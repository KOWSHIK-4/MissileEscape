# Missile Escape

A neon arcade survival game: steer your ship, dodge the heat-seeking missiles, and make the swarm collide with itself.

## Play

Open `index.html` in a browser. No dependencies or build step required.

- Move: **WASD** or **arrow keys**
- Pause/resume: **Space** or the pause button
- Touch: drag across the playfield on a mobile device

Your personal best is saved in the browser.

## Deploy

The included GitHub Actions workflow enables GitHub Pages and deploys the site whenever changes are pushed to `main`. The published URL is shown on the repository's **Settings → Pages** page and in the deployment workflow run.
